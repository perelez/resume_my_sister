# Сайт-портфолио

Многостраничный адаптивный сайт-визитка, разработанный для презентации портфолио и услуг креативного директора. Проект включает в себя главную страницу, разделы с реализованными проектами, публикациями и контактной информацией.

## 🚀 Технологии и инструменты
*   **HTML5** — семантическая и валидная верстка.
*   **CSS3** — стилизация, использование Flexbox/Grid для позиционирования элементов, адаптивность под мобильные устройства.
*   **JavaScript (Vanilla)** — интерактивные элементы и логика работы меню.
*   **Vite** — сборщик проекта для быстрой разработки и оптимизации production-сборки.
*   **Git** — контроль версий.

## 🛠 Реализованный функционал
*   **Многостраничная структура:** Реализованы отдельные страницы для каждого проекта (`project-001.html`, `project-002.html` и т.д.), а также страницы контактов и публикаций.
*   **Адаптивная верстка:** Сайт корректно отображается на экранах смартфонов, планшетов и десктопов (реализовано с использованием медиа-запросов).
*   **Кроссбраузерность:** Проверена корректная работа в основных современных браузерах.
*   **Современный стек:** Использование Vite позволяет быстро собирать проект и минифицировать файлы для продакшена.

## 📂 Структура проекта
*   `public/` — статические файлы (изображения, шрифты, иконки).
*   `src/` — исходные файлы стилей и скриптов.
*   `*.html` — страницы проекта (главная, проекты, публикации, контакты).
*   `vite.config.js` — конфигурация сборщика.
*   `package.json` — зависимости проекта и npm-скрипты.

## ⚙️ Как запустить проект локально

1.  Склонируйте репозиторий:
    ```bash
    git clone https://github.com/perelez/resume_my_sister.git
Перейдите в папку проекта:

bash
cd resume_my_sister
Установите зависимости (нужен установленный Node.js):

bash
npm install
Запустите сервер для разработки:

bash
npm run dev
Откройте в браузере адрес, который появится в терминале (обычно http://localhost:5173).
